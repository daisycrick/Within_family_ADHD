Reduced_population_MR.R file runs the MR analysis for the population-level data.
Reduced_siblings_MR.R file runs the MR analysis for the sibling-level data.
Creating_dataframe.R creates the data frame under different levels of shrinkage. 

Ld_and_pleiotropy_breakdown file provides information about the snps in ld disequilibrium or pleiotropic. It highlights the SNPs that are dropped in the MR analysis and explains why. 
Population_harmonized_SNPinfo provides information such as F-statistic, Effect Allele, Other Allele, etc for the population-based MR analysis for every phenotype included post harmonisation. 
Siblings_harmonized_SNPinfo provides information such as F-statistic, Effect Allele, Other Allele, etc for the population-based MR analysis for every phenotype included post harmonisation.
